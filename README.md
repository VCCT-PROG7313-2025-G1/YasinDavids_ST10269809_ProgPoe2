# Android App - Getting Started

This guide explains how to download and run the Android app using Android Studio.

---

Run the App Using Android Studio

Requirements

- [Java Development Kit (JDK) 17+](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html)
- [Android Studio](https://developer.android.com/studio)
- Android SDK (installed through Android Studio)

---

Steps

1. **Download the Project**
   - Click the green **"Code"** button on this GitHub repository and choose **"Download ZIP"**, or run:
     ```bash
     git clone https://github.com/your-username/your-repo-name.git
     ```
   - If you downloaded the ZIP, extract it to a location on your computer.

2. **Open the Project in Android Studio**
   - Launch Android Studio.
   - Click **"Open"** and navigate to the project folder.
   - Wait for Android Studio to **index and build** the project.

3. **Connect a Device or Set Up an Emulator**
   - You can use a **real Android device** (with USB debugging enabled), or
   - Create an **Android Virtual Device (AVD)** by clicking **Device Manager > Create Device**.

4. **Run the App**
   - Click the **green play button** â¶ï¸ in Android Studio.
   - Select your device or emulator.
   - The app will build and launch automatically.
